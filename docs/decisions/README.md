# Decision log (ADRs)

Every substantial change of scope, data source, method or tooling is recorded
here as a short Architecture Decision Record. ADRs are never edited after being
accepted; a later ADR supersedes an earlier one.

File name: `NNNN-short-title.md`. Template:

```markdown
# NNNN: Title

- Status: proposed | accepted | superseded by NNNN
- Date: YYYY-MM-DD

## Context
## Decision
## Consequences
```
